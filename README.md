# 🌐 SharperEdge

**SharperEdge** is a community-driven project to harden Microsoft Edge—mirroring the philosophy of BetterFox for Firefox—with modular profiles for privacy, performance, and security.

## ✨ Highlights
- 🔒 Strict lockdown with optional hardened DoH and WebRTC controls
- ⚖️ Balanced defaults for daily users seeking strong protections
- ⚡ Performance-optimized tweaks with minimal friction
- 🪟 Native Windows 10/11 support via registry policies and PowerShell automation
- 🛡️ Backup & restore built-in; changes are scoped and safe

## 🚀 Installation

- One-liner install via PowerShell script (`edge-apply.ps1`)
- Or double-click `.reg` files for HKCU-only configuration
- Verified on latest Microsoft Edge (Chromium) and Windows 11 Pro
